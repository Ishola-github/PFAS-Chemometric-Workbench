# PFAS Chemometric Workbench (Research Use Only)

> **An open-source chemometric platform for analytical chemistry, environmental monitoring, and PFAS research.**

PFAS Chemometric Workbench is a **Research Use Only (RUO)** software platform for multivariate analysis of analytical chemistry data. It provides reproducible workflows for spectral preprocessing, principal component analysis (PCA), multivariate outlier detection, and predictive chemometric modeling to support analytical laboratories and environmental research.

The platform is designed for scientists working with spectroscopy, chromatography, metabolomics, biomonitoring, and PFAS datasets.

---

# Overview

The workbench supports exploratory data analysis, quality assessment, and model interpretation using established chemometric methods while providing a roadmap toward AI-assisted analytical review.

Current capabilities include:

* Principal Component Analysis (PCA)
* Spectral preprocessing
* Multivariate outlier detection
* Partial Least Squares (PLS) regression
* Explainable AI support
* Applicability-domain analysis
* LC-MS/MS quality review (roadmap)

---

# Scientific Background

Modern analytical chemistry routinely generates high-dimensional datasets that require multivariate statistical techniques for interpretation.

Chemometric approaches such as PCA and PLS are widely used in:

* Environmental monitoring
* PFAS analysis
* Pharmaceutical quality control
* Food safety
* Clinical toxicology
* Metabolomics
* Spectroscopy
* Biomonitoring

PFAS Chemometric Workbench provides an open and reproducible platform to explore these datasets while maintaining transparent analytical workflows.

# Features

## Data Import

* CSV analytical datasets
* Synthetic NIR-like spectral demonstration dataset
* Built-in outlier injection

## Data Preprocessing

* Mean centering
* Autoscaling
* Standard Normal Variate (SNV)
* Multiplicative Scatter Correction (MSC)
* Savitzky-Golay smoothing
* First-derivative preprocessing

## Principal Component Analysis

* PCA score plots
* Loading plots
* Scree plots
* Explained variance
* Cumulative variance

## Multivariate Outlier Detection

* Hotelling's T²
* Q-residual (SPE)
* Statistically derived control limits
* Flagged sample reports
* CSV export

## Partial Least Squares Regression

* Cross-validation
* Component optimization
* RMSE
* MAE
* R²
* Prediction dashboard
* Model export

## Explainability

* Feature importance ranking
* Coefficient interpretation
* Applicability domain analysis
* Mahalanobis distance
* Leverage calculations
* Uncertainty assessment
* Review-required flags
